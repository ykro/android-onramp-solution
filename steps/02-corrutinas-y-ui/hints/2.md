# Pista 2. Qué usar en cada ejercicio

- Ejercicio 1. Construye el `Flow` con `flow { }`. Recorre los números de `from` hacia abajo hasta `0`, emite cada uno y espera con `delay` entre ellos. Con `from` negativo, el recorrido simplemente no tiene elementos.
- Ejercicio 2. Un `try` con dos `catch`. El primero, para la cancelación, la vuelve a lanzar; el segundo convierte el error en texto.
- Ejercicio 3. Pide el contador a `memory.remember` con la clave que esperan los tests. Lee y escribe su `value` en el texto y en las dos lambdas.
- Ejercicio 4. Compose tiene una función que guarda un valor entre recomposiciones; envuelve con ella la creación del estado. El botón «Reiniciar» se escribe igual que el de «Sumar sesión», con otra acción en `onClick`.

Si quieres ver la forma, abre [la pista 3](3.md).
