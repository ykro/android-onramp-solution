# Pista 2. Las piezas

- Crea una instancia de `Json` configurada para ignorar campos desconocidos y guárdala como propiedad del cliente.
- Arma un `Request` con la URL de `/books` y ejecútalo con el `client`. Cierra la respuesta al terminar (`use`).
- Si la respuesta no es exitosa, devuelve el error con su código.
- Decodifica el texto del cuerpo como `List<BookDto>` dentro de un `try`, y convierte la `SerializationException` en `ParseError`.
- Todo lo anterior va dentro de `withContext(dispatcher) { ... }`. Un segundo `try` alrededor del request convierte la `IOException` en `NetworkError`.

Si quieres ver la forma, abre [la pista 3](3.md).
