# Pista 2. Qué usar en cada ejercicio

- Ejercicio 1. Crea el scope, ejecuta la lambda sobre él y devuelve lo que arma el scope. Una lambda con receptor se llama como si fuera un método del objeto.
- Ejercicio 2. Un `when (state)` con una rama por subtipo. Con `is` revisas el tipo y Kotlin te deja leer sus propiedades en esa rama.
- Ejercicio 3. Cambia el tipo de la lista a uno de solo lectura. Para agregar o quitar, construye una lista nueva (`+` agrega, `drop(1)` quita el primero) y un estado nuevo con `copy`. `MutableStateFlow.update { }` recibe el estado actual y guarda el que devuelves.

Si quieres ver la forma, abre [la pista 3](3.md).
