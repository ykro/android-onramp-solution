# Pista 1. Tres caminos de una respuesta

Una respuesta puede terminar de tres formas, código de error, cuerpo que no se puede leer o lista de libros. Cada una corresponde a un `ApiResult`. Primero revisa el código y solo después intenta leer el cuerpo.

Por defecto, `kotlinx.serialization` falla cuando el JSON trae un campo que la clase no declara. Busca en la [guía de JSON](https://github.com/Kotlin/kotlinx.serialization/blob/master/docs/json.md#ignoring-unknown-keys) cómo cambiar eso.

Si ya tienes claros los tres caminos, abre [la pista 2](2.md).
