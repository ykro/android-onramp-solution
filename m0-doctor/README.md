# Paso 0 (`m0-doctor`)

Este módulo revisa tu entorno (JDK 21 o superior y Android SDK) y trae tu primer programa en Kotlin. La guía completa está en [steps/00-entorno-y-kotlin/README.md](../steps/00-entorno-y-kotlin/README.md).

## Comandos

```bash
./gradlew doctor --no-parallel
./gradlew :m0-doctor:run --no-parallel
./gradlew paso0 --no-parallel
```
